# Repositorio_Teste

## Painel do Projeto — Cronograma Interativo de Gestão de Projeto

Abra o arquivo [`index.html`](./index.html) diretamente no navegador (nenhum servidor ou instalação necessária).

Aplicação single-file (HTML + CSS + JavaScript puro) para gerenciar um projeto do início ao fim:

- **Dashboard** com indicadores gerais, alertas inteligentes, próximas ações e anotações rápidas.
- **Tarefas** em tabela agrupada por fase, com filtros avançados e ações rápidas (concluir, reabrir, duplicar, excluir, mudar status/prioridade).
- **Kanban** com colunas por status e arrastar-e-soltar.
- **Cronograma** em estilo Gantt, com barras por período e marcador do dia atual.
- **Calendário** mensal com as tarefas por data.
- **Banco de Ideias**, com conversão de ideia em tarefa.
- **Histórico** de alterações e **Configurações** (fases, categorias, tema claro/escuro, backup em JSON, exportação em CSV e impressão).

Os dados são salvos automaticamente no `localStorage` do navegador — nada é perdido ao fechar ou atualizar a página. Alguns dados de demonstração são carregados na primeira abertura e podem ser removidos em Configurações.
